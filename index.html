🌐 Apa itu Jaringan Komputer?

Slide 2 · Konsep Dasar

Jaringan komputer adalah kumpulan dua perangkat atau lebih yang saling terhubung untuk bertukar data dan berbagi sumber daya (resource).

🗼

Node

Perangkat: komputer, server, printer, smartphone.

🔗

Link

Media penghubung: kabel UTP, fiber optik, sinyal WiFi.

🤝

Protokol

Aturan komunikasi: TCP/IP, HTTP, DNS, dll.

Klik kotak di atas untuk menandainya sebagai dipelajari.

💡 Coba klik: Skala Jaringan LAN ↔ MAN ↔ WAN

LAN Satu gedung/kampus — kecepatan tinggi, lingkup kecil.

MAN Satu kota — menghubungkan 2 kantor / beberapa LAN.

WAN Antar kota/negara — internet adalah WAN terbesar.

🔧 Perangkat Jaringan

Slide 4 · Flip Card

Klik kartu untuk membalik dan membaca fungsi tiap perangkat:


🍃

Hub

Layer 1 · klik untuk balik

Hub

Meneruskan data ke semua port (broadcast). Satu collision domain, tidak cerdas.

🔀

Switch

Layer 2 · klik untuk balik

Switch

Mengirim data ke port tujuan berdasarkan alamat MAC. Memisahkan collision domain.

🚏

Router

Layer 3 · klik untuk balik

Router

Menghubungkan jaringan berbeda, memilih jalur terbaik berdasarkan alamat IP.

📶

Access Point

Layer 2 · klik untuk balik

Access Point

Menghubungkan perangkat nirkabel (WiFi) ke jaringan kabel.

📡

Modem / ONT

Layer 1 · klik untuk balik

Modem / ONT

Mengubah sinyal ISP (listrik/optik) menjadi sinyal digital komputer.

🛡️

Firewall

Keamanan · klik untuk balik

Firewall

Menyaring lalu lintas masuk/keluar sesuai aturan keamanan jaringan.

🏁 Rangkuman & Kesiapan Quiz

Slide 7
  • Media Transmisi: tembaga (listrik) — murah tapi rentan interferensi; fiber optik (cahaya) — cepat & imun EMI; wireless — fleksibel tapi rawan gangguan.
  • Perangkat: Switch (MAC), Router (IP), AP (nirkabel), Firewall (pengaman).
  • OSI: 7 layer dengan enkapsulasi Data → Segment → Packet → Frame → Bit.
  • Topologi: Star mudah dikelola namun bergantung pada Switch pusat; Full Mesh paling andal namun biaya kabel tertinggi.
